# KI-in-der-Produktion---3D-Keypoint-Detection---KeyGrid
Implementierung und eigenständiges Training von Key-Grid zur unsupervised 3D Keypoint Detection auf Punktwolken. Im Rahmen der Vorlesung „Künstliche Intelligenz in der Produktion" an der Hochschule Karlsruhe trainiert auf die KeypointNet-Kategorien Airplane.
